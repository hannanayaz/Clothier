# Clothier

Clothier is a professional clothing catalog and retail inventory management Android app.

## Features

- Clothing catalog for Top Wear and Bottom Wear
- Dynamic clothing categories
- Custom category creation
- Admin Mode
- Add and manage stock
- Product details, prices, sizes, colors, fabric and fit
- Top Wear sizes: S, M, L, XL, XXL, 3XL, 4XL
- Bottom Wear sizes: 28–44
- UPI, cash and card payment options
- Local/offline data storage
- Responsive phone and tablet interface
- Clothier branding and app icon

## Android App

App name: Clothier

Package name: `com.clothier.catalog`

The project includes a GitHub Actions workflow for building the Android APK.
